# Character rig source

The runtime rig is `requiem/player/art/girl_rig_v2/`. This folder retains the original generated modular source, deterministic bake scripts and manifests. Runtime provenance is in `PROVENANCE.txt` beside the exported assets. No authoring dependency is required to play the game.

Use Python 3 and Pillow (the preview uses Pillow's sized default font). From this folder:

```sh
python export_assets.py
python export_action_layers.py --review-dir previews
python breath_rig.py --review-dir previews
python throw_rig.py --review-dir ../../requiem/testing/captures/throw_review
python prayer_rig.py --review-dir ../../requiem/testing/captures/prayer_review
python sprint_rig.py --review-dir ../../requiem/testing/captures/sprint_review
```

`export_assets.py` builds the original directional idle/walk/sprint frames and the Godot SpriteFrames resource. `export_action_layers.py` builds the original equipped upper-body, separate leg and grip layers plus attachment anchors. These base locomotion exports retain their authored 0.90 s walk/sprint cycle; the live renderer now selects the dedicated sprint layers described below. Outputs go to the runtime rig folder; manifests remain here. The combined lower-body inspection sheet and optional previews go to ignored `previews/`.

`breath_rig.py` adds the Hold Your Breath upper-body track without changing the locomotion exports. Its 222-frame sheet contains seven tracks in neutral plus five flashlight aim modes: inhale (6 frames), hold (1), strain (4), release (6), gasp (6), recovery (8), and loud release (6). Frame index is `mode * 37 + track.offset + frame`; all cells are 256 × 256 with pivot (128, 128), world scale 0.5 and the same wrist registration as the existing rig. The atlas is 2048 × 7168.

`breath_layers_manifest.json` records track ranges, timings, authored part transforms and joint geometry. `breath_layer_anchors.gd` is the export-safe runtime companion. `CharacterRigLayers.get_breath_pose(track, phase, aim_step, equipped)` takes normalized phase 0–1 and returns a registered upper sprite and matching wrist/muzzle sockets. Transitions are baked by interpolating individual cutout transforms; do not crossfade two different wrists/cuffs. Inhale starts at exact idle; release, loud release and recovery end at exact idle. Gasp's final frame is recovery's first frame. Lower-body foot contacts and the rigid hand/flashlight attachment are shared with locomotion.

Live timings are inhale 0.20 s, release 0.46 s, loud release 0.55 s, gasp 0.28 s, then recovery for the remaining forced lock (1.72 s at the default two-second lock). Hold is indefinite. Strain loops at 0.8–1.55 Hz according to lung/exertion pressure, so its metadata duration is zero.

`throw_rig.py` adds Throw 03: 12 windup frames and 10 follow-through frames per mode, six modes / 132 upper-body frames. The 2048 × 4352 atlas shares the same cell, pivot and scale. The anatomical left hand throws while the right hand keeps its existing flashlight grip. Anticipation follows the mechanic's 0.50 s windup; the exact final windup pose joins the first follow-through pose at the actual release event. Follow-through settles over 0.32 s within the existing cooldown. `throw_layers_manifest.json` records fixed bone lengths, source-part transforms, and a throwing-palm socket derived from the drawn pixels. `throw_layer_anchors.gd` exports the matching palm, wrist and muzzle for every frame. `python throw_rig.py --validate-only` verifies all 132 poses, all 12 byte-identical idle endpoints, and all six release seams.

`prayer_rig.py` adds Prayer 04: eight entry, eight loop and eight exit frames in each of six modes, 144 upper poses in a 2048 × 4608 sheet. Entry lowers into a readable kneel and gathers the free left palm over 0.42 s; the sustained loop spans 2 s; exit reverses entry exactly over 0.38 s. Two separate 24-frame leg sheets fold the boots behind the back, using the original trouser and boot source parts. The altar owns acceptance and elapsed ritual time; its default duration remains 12 s. Early release reverses from the current entry pose, and re-entry during exit resumes from the same bow. `prayer_layers_manifest.json` records part transforms and matching wrist/muzzle geometry; `prayer_layer_anchors.gd` is the runtime companion. `python prayer_rig.py --validate-only` checks 144 upper poses and 48 leg plates, exact standing silhouettes, continuous seams, byte-identical reversed entry/exit pairs and exposed rear boots in every equipment mode. The existing locomotion leg sheets remain unchanged; prayer temporarily selects its own folded lower pose.

`sprint_rig.py` adds the dedicated sprint: eight upper poses in neutral and five equipped aim modes, 48 poses in `sprint_upper_layers.png` (2048 × 1536), plus eight relative travel directions × eight poses in each independent `sprint_left_leg_layers.png` and `sprint_right_leg_layers.png` sheet (64 poses each, 2048 × 2048). Cells remain 256 × 256 at pivot (128, 128) and world scale 0.5. Upper packing is `mode * 8 + frame`; lower packing is `direction_index * 8 + frame`, using the existing direction order.

The sprint has a nominal 0.60 s cycle at the existing 172.8 px/s speed, covering 103.68 world pixels per full stride. `PlayerMotion` advances its sprite phase from actual displacement divided by that stride distance, so slower travel slows the cycle and pushing into a wall does not keep it running. `CharacterAnimation` preserves phase through walk/sprint transitions. Walking and held-breath poses retain the footstep clock; gameplay hearing rates are unchanged. Audible footsteps now follow resolved contacts through `FootstepAudio` (see `tools/audio/README.md`). `CharacterRigLayers.get_pose` and `get_lower_pose` select the new sprint resources and matching anchors, with the existing per-foot support solver retaining planted world positions.

The silhouette uses a stronger forward lean, tucked alternating arm drive and a restrained two-beat head/shoulder rhythm. Free upper arms and forearms each retain 18-pixel projected lengths; the equipped arm retains two 16-pixel segments, its 12-degree elbow and one rigid hand/torch attachment. Rigid 18 × 24 boots stay in separate anatomical lanes with at most seven source pixels of lateral excursion and unchanged three-degree toe splay. Folded knee recovery keeps each projected trouser segment bounded to 32 pixels. The 0.375 contact fraction, contact/swing progress metadata and passing frames 2/6 remain compatible with the support solver.

`sprint_layers_manifest.json` records the original source hash, geometry, timings and all 48 upper / 64 lower anchor entries. `sprint_layer_anchors.gd` exports the runtime sockets, `CYCLE_SECONDS` and `STRIDE_DISTANCE`. `python sprint_rig.py --validate-only` checks fixed upper-limb lengths, equipped elbow geometry, rigid boot headings, separate lanes, bounded reach, cyclic wrapping and contact velocity against gameplay speed. The review directory includes old/new comparisons at gameplay size, neutral/equipped sequence sheets, five aim offsets and all eight relative and world directions. Baking this addition writes only sprint-specific resources; original locomotion, breath, throw and prayer exports are preserved byte for byte.

Reimport in Godot after baking, then run player motion, actions, dense pose and rendered lighting checks. Preserve the source sheet and its hash; do not treat it as disposable test output. Dedicated death/caught and ordinary idle-breath clips remain unfinished.
